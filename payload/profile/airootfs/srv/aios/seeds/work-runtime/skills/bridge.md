# Operator bridge

---
name: bridge
description: Approval-gated access to the human's private paths.
---

The operator computer is the human's machine (or the private paths they keep
out of the managed substrate). Access is approval-gated.

- Shell, structured read, copy to workspace, copy from workspace.
- A path on one side is not visible on the other. Copy is verbatim. Not a
  mount.
- The command does not run until the human approves.
- Login, 2FA, captcha, and payment are not operator-computer work. Hand the
  interactive surface to the human. The agent never sees the password.
